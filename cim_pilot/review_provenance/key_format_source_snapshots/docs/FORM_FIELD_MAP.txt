HTML FORM LABELS AND JSON FIELDS

The form reads and writes these existing JSON paths. Display captions do not rename keys.
The controlled judgment codes remain ALIGNED, POTENTIAL_MISMATCH and UNRESOLVED; null means not yet rated.
An Evidence note is the existing optional support_note. Exact quotations must remain exact.

Reviewer
  JSON: reviewer_id
  Your actual reviewer code.

Review status
  JSON: review_status
  Record the review work actually completed; filling text does not complete a review.

Local task question
  JSON: local_question
  One local question about the same task step or event for both participants.

First participant
  JSON: focal_pair[0]
  First of the two actual participants being compared.

Second participant
  JSON: focal_pair[1]
  Second of the two actual participants being compared.

Use as focus
  JSON: focus_source_ids
  Select a prefix turn using this button; the selected turn can be removed with Remove focus.

Exact expression
  JSON: focus_quotes[].quote
  Exact wording from the selected prefix turn; shorten it without paraphrasing.

Focus source
  JSON: focus_quotes[].source_id
  Displayed from the selected prefix turn; change the focus selection to choose another turn.

Focus speaker
  JSON: focus_quotes[].speaker
  Displayed from the selected prefix turn.

Participant
  JSON: participant_meanings_with_source_quotes[].participant_id
  The participant whose interpretation is recorded in this reading.

Evidence support
  JSON: participant_meanings_with_source_quotes[].support
  Use supported, possible, unsupported, or null while pending. Map presence or a bare acknowledgment alone is insufficient support.

Interpretation
  JSON: participant_meanings_with_source_quotes[].meaning
  Describe what this participant means in plain language.

Evidence note
  JSON: participant_meanings_with_source_quotes[].support_note
  Optional plain-language explanation of why the cited speech supports this reading or leaves it only possible.

Evidence source
  JSON: participant_meanings_with_source_quotes[].source_quotes[].source_id
  Choose an exact turn in the permitted dialogue prefix.

Exact evidence
  JSON: participant_meanings_with_source_quotes[].source_quotes[].quote
  Exact quotation from the chosen source. A supported reading needs the participant’s own expressed evidence.

Source speaker
  JSON: participant_meanings_with_source_quotes[].source_quotes[].speaker
  Copied from the selected prefix turn; source changes update this value.

Same task / event scope
  JSON: task_outputs.scope
  Keep the task question, event, phase and required facts the same for both participants.

<participant_id> · consequence
  JSON: task_outputs.participant_outputs[participant_id]
  Describe what follows from this participant’s supported reading. The participant identifier replaces the placeholder in the caption.

Comparison in words
  JSON: task_outputs.comparison
  Explain whether the supported consequences agree, differ or remain uncertain.

What is still unknown? One reason per line
  JSON: task_outputs.blocking_reasons
  One unknown fact or consequential alternative per line.

Supported consequences JSON
  JSON: task_outputs.supported_consequences
  Optional typed consequence sets, keyed by the two focal participants. Null or UNKNOWN in a required value prevents a determinate F7 judgment.

Could uncertainty change the conclusion?
  JSON: blocking_uncertainty
  Could missing support, facts, binding, phase or another unresolved reading change the comparison?

Review judgment
  JSON: provisional_label
  ALIGNED, POTENTIAL_MISMATCH or UNRESOLVED after analysis; null means not rated yet.

Why this judgment? Prefix evidence only
  JSON: prefix_only_rationale
  Explain the label using only permitted prefix/context evidence.

Evidence checked?
  JSON: evidence_verified
  Confirm source/support and required context checks; exact-string matching alone is insufficient.

Include in pilot?
  JSON: include_in_pilot
  Human recommendation; this does not automatically change pilot_selection.csv or a case role.

Selection / exclusion reason
  JSON: inclusion_or_exclusion_reason
  Why include, defer or exclude this particular case.

I checked the content now entered against the available evidence.
  JSON: review_metadata.human_content_confirmed
  Confirm only after checking the current content yourself.

Assistant drafts
  JSON: review_metadata.prior_exposure.assistant_draft
  Record whether drafts were seen before the first prefix judgment; do not rewrite declared history.

System predictions
  JSON: review_metadata.prior_exposure.system_outputs
  Record whether model predictions were seen before the first prefix judgment.

Released / other labels
  JSON: review_metadata.prior_exposure.released_labels
  Record whether released or another reader’s labels were seen before the first prefix judgment.

Later dialogue or outcomes
  JSON: review_metadata.prior_exposure.later_evidence
  Record whether later dialogue or outcomes were seen before the first prefix judgment.

Exposure notes
  JSON: review_metadata.prior_exposure.notes
  Brief factual notes about prior exposure; detailed provenance may be retained separately.

First prefix review completed
  JSON: review_metadata.prefix_first_review_completed
  Record whether the initial prefix-based judgment was saved before later evidence/draft consultation.

Separate later-evidence review completed
  JSON: review_metadata.later_evidence_review_completed
  Only after the separate later-evidence review actually occurs.
